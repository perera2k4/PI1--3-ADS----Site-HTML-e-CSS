# 🤠 Red Dead Redemption 2 - Website Temático

## 📋 Descrição do Projeto

Este projeto é um website temático dedicado ao jogo Red Dead Redemption 2, desenvolvido como parte do trabalho de **Desenvolvimento Web com HTML e CSS**. O site apresenta informações detalhadas sobre o jogo, incluindo história completa, missões, mapa interativo, conquistas, personagens e galeria multimídia.

## 🎯 Funcionalidades Implementadas

### 🗺️ Mapa Interativo
- **Navegação por Arrastar**: Sistema de drag para explorar o mapa
- **Zoom Dinâmico**: Controle de zoom com scroll do mouse
- **Centralização Automática**: Mapa se ajusta automaticamente ao tamanho da tela
- **Limites de Movimento**: Navegação restrita aos limites do mapa

### 📖 Sistema de Navegação
- **Menu Principal**: Navegação consistente em todas as páginas
- **Links Relativos**: Sistema de navegação entre páginas otimizado
- **Design Temático**: Estilização que remete ao ambiente do Velho Oeste

## 🛠️ Tecnologias Utilizadas

- **HTML5**: Estrutura semântica das páginas
- **CSS3**: Estilização avançada e layouts responsivos
- **JavaScript Vanilla**: Funcionalidade do mapa interativo
- **Custom Fonts**: Fonte Chinese-Rocks para identidade visual
- **CSS Grid/Flexbox**: Sistemas de layout modernos

## 💡 Funcionalidades Técnicas

### JavaScript Features
- **Event Listeners**: Controle de mouse e teclado no mapa
- **Transform Matrix**: Manipulação de posição e escala
- **Clamp Function**: Limitação de valores para navegação
- **Responsive Handlers**: Adaptação a mudanças de janela

### CSS Features
- **Custom Fonts**: @font-face para tipografia única
- **Flexbox/Grid**: Layouts modernos e flexíveis
- **Background Images**: Múltiplas camadas de textura
- **Hover Effects**: Interatividade nos elementos
- **Responsive Design**: Media queries para adaptabilidade

### HTML Features
- **Semantic Structure**: Uso apropriado de tags HTML5
- **Navigation System**: Links relativos organizados
- **Accessibility**: Alt texts e estrutura acessível
- **Performance**: Otimização de carregamento de recursos
